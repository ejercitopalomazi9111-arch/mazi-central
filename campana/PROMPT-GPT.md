# Este prompt quedó viejo

Se escribió para producir el expediente de una candidatura que se llamaba
**Organiza · Optimiza · Actualiza**. Esa identidad ya no existe.

La candidatura es **CET — Comprende · Ejecuta · Trasciende**, y el documento
que ese prompt iba a producir **ya está escrito y entregado a Dirección**.

## Dónde está lo vigente

| Qué | Dónde |
|---|---|
| El documento entregado, completo | `campana/CET-documento.txt` |
| El manual de marca, con las mediciones | `campana/marca.html` |

| La estructura de la Sociedad | `campana/planta.html` |
| El tablero de pendientes | `campana/mapa.html` |

El documento se arma pegando `CET-documento.txt` en **Reportes** (`/reportes/`),
con papel del Instituto Rembrandt. De ahí salen el PDF normal y el de ahorro de
tinta.

## Por qué no se reescribió para CET

Porque ya no hace falta: el texto existe y está entregado. Un prompt para
generarlo otra vez sólo serviría para producir una segunda versión que
contradiga a la primera — que es exactamente el problema que este archivo
tenía.
