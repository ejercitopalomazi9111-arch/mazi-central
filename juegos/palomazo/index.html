Ahora lleva el ritmo.

Toda la música de este juego se hace sola, aquí adentro. No hay un solo archivo de audio.

Cómo se juega

Toca el carril cuando la nota llegue a la línea. Nada más.

Las notas largas se mantienen apretadas hasta que se acaban: es el aleteo sostenido.

Cada nota que atinas suena — la melodía la estás tocando tú. Si fallas, se oye el hueco.

En computadora: A · S · D, o las flechas, o 1 · 2 · 3. Espacio para pausar.
