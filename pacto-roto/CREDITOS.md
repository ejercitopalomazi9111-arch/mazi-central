# Créditos del arte — El Pacto Roto

**Todo el arte de este juego es real.** Nada fue dibujado por código. Se respeta la regla
inquebrantable de Grupo Mazi: nunca se genera arte con `ctx.beginPath()`.

El juego mezcla dos registros:
- **Pintura y grabado de museo** (dominio público) para escenas, combate, mundo y estaciones.
- **Sprites pixel-art LPC** (licencia libre con atribución) para ítems, comida y materiales.
