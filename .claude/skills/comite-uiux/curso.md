PROMPT MAESTRO — ENTRENAMIENTO EXTREMO DE UI/UX, MOTION Y DESARROLLO WEB

Toda tu página está mal y Luis me pidió que te entrene yo, así que iniciemos.

No quiero que simplemente “hagas una página bonita”.

Quiero que construyas una experiencia web que parezca haber sido diseñada por un equipo completo de UX designers + UI designers + motion designers + frontend engineers + interaction designers + creative developers.

Y quiero que aprendas algo desde el principio:

Una página increíble no es una colección de animaciones. Es una experiencia donde cada movimiento, sonido, transición, botón, sombra, cambio de estado y elemento visual tiene una razón.

3. LA REGLA MÁS IMPORTANTE

Cada elemento debe tener estados.

Por ejemplo, un botón NO es simplemente:

[ ENVIAR ]

Debe tener como mínimo:

default
hover
focus
pressed
loading
success
error
disabled

Y cada estado debe sentirse diferente.

Ejemplo:

DEFAULT

Botón en posición:

x = 620
y = 420
width = 240
height = 64

HOVER

Al entrar el cursor:

* escala: 1.00 → 1.035;
* desplazamiento vertical: 0 → -3 px;
* sombra: aumenta;
* borde: aumenta ligeramente de luminosidad;
* icono: se desplaza 4 px;
* duración: 160 ms;
* easing: cubic-bezier(.2,.8,.2,1).

PRESSED

Al hacer click:

* escala: 1.035 → 0.96;
* duración: 70 ms;
* sombra disminuye;
* botón baja 2 px;
* aparece una pequeña onda desde el punto exacto del click.

LOADING

El texto:

ENVIAR

se convierte en:

● ● ●

o:

ENVIANDO...

El botón NO debe cambiar bruscamente.

SUCCESS

Debe aparecer:

* check;
* pequeño rebote;
* expansión circular;
* feedback visual;
* mensaje contextual.

7. MICROINTERACCIONES

Llena la aplicación de pequeños detalles.

Ejemplos:

Cursor magnético

Cuando el cursor se acerca a un botón:

distance < 80px

el botón comienza a desplazarse ligeramente hacia el cursor.

Máximo:

12px

Nunca debe perseguir al cursor completamente.

⸻

Ripple

Al hacer click:

1. detectar coordenadas del pointer;
2. calcular posición relativa dentro del botón;
3. crear círculo;
4. radio inicial: 0;
5. radio final: 180px;
6. opacity: 0.35 → 0;
7. duración: 500ms;
8. easing: ease-out.

ÚLTIMA REGLA

No quiero que intentes impresionarme diciendo:

“Esta página tiene animaciones increíbles.”

Quiero que puedas demostrarlo.

Quiero poder señalar cualquier elemento y preguntarte:

“¿Qué pasa si hago click aquí?”

Y que exista una respuesta.

“¿Qué pasa si mantengo presionado?”

Respuesta.

“¿Qué pasa si lo arrastro?”

Respuesta.

“¿Qué pasa en móvil?”

Respuesta.

“¿Qué pasa si no hay conexión?”

Respuesta.

“¿Qué pasa si tengo reduced motion?”

Respuesta.

“¿Qué pasa si falla?”

Respuesta.

“¿Qué pasa si paso el cursor?”

Respuesta.

“¿Qué pasa en el frame 17?”

Respuesta.

Eso es lo que quiero que entiendas.

No estás construyendo una página web.
